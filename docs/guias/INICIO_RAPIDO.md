# 🚀 Inicio Rápido - PROVETCARE

## Opción 1: Inicio Automático (Recomendado) ✨

Simplemente ejecuta:

```powershell
.\iniciar-desarrollo.ps1
```

Esto abrirá automáticamente:
- ✅ Backend en puerto 5000
- ✅ Frontend en puerto 5173
- ✅ Navegador con la aplicación

---

## Opción 2: Inicio Manual (Dos Terminales)

### Terminal 1: Backend
```powershell
cd server
npm run devo
```

### Terminal 2: Frontend (nueva terminal)
```powershell
cd client
npm run dev
```
