Sistema Web para Agendamiento de Citas Veterinarias

📋 Introducción al Proyecto

Problemática

Las clínicas veterinarias pequeñas y medianas todavía gestionan sus citas por WhatsApp, llevan los historiales médicos en cuadernos, y las recetas las escriben a mano. Esto genera pérdida de información, citas olvidadas, y una experiencia poco profesional para los clientes.

Solución: PROVETCARE

  • ✅ Sistema de calendario en línea para agendar citas
  • ✅ Base de datos centralizada para historiales médicos
  • ✅ Generación automática de recetas y facturas en PDF
  • ✅ Recordatorios por email 24 horas antes de cada cita
  • ✅ Chat en tiempo real entre veterinarios y clientes
  • ✅ Sistema de facturación completo
  • ✅ Control de acceso basado en roles (Cliente, Veterinario, Admin)

🏗️ Arquitectura del Sistema

Patrón MVC en el Backend

  • Routes (Rutas): Definen los endpoints HTTP como GET /api/appointments
  • Controllers (Controladores): Contienen la lógica de negocio
  • Middleware: Manejan autenticación y validación
  • Services (Servicios): Funcionalidades auxiliares

Flujo de Autenticación

  • 1. Usuario envía credenciales a /api/auth/login
  • 2. Servidor verifica contraseña con Bcrypt
  • 3. Si es válida, genera token JWT firmado
  • 4. Cliente guarda token en localStorage
  • 5. Cada petición incluye Authorization: Bearer {token}
  • 6. Middleware verifica token antes de procesar
